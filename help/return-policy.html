Return Policy

We want you to be happy with what you ordered. If something isn't right, here's how returns work.

Return window

Items can be returned within 7 days of delivery, provided they're unused and in their original packaging.

How to start a return

Contact us via the Contact page with your order ID and the reason for the return, and we'll guide you through the next steps.

Refunds

Once we receive and inspect the returned item, refunds are processed back to your original payment method within 5–7 business days.

Non-returnable items

For hygiene reasons, some items (e.g. pierced jewelry) may not be eligible for return once opened — check the product page or ask us before ordering if unsure.

This is a starting-point policy — adjust the return window and exceptions to match how you actually want to run your store.
